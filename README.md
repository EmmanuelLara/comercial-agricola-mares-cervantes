# Comercial Agrícola Mares Cervantes - Sistema de Gestión

Este proyecto es una migración de un sistema de almacén basado en SQL a una arquitectura moderna utilizando **Node.js**, **Express**, **MongoDB** y **EJS**.

## Requisitos

- Node.js (v14+)
- MongoDB (Running locally or on Atlas)

## Instalación

1. Clonar el repositorio.
2. Ejecutar `npm install`.
3. Configurar el archivo `.env` con tu URI de MongoDB.
4. Ejecutar `npm start` o `node app.js`.

## Estructura

- `/models`: Schemas de Mongoose (Product, User, Client, Supplier, Sale, Purchase, Filter, Business).
- `/routes`: Rutas para la lógica de negocio y API.
- `/views`: Plantillas EJS para la interfaz de usuario.
- `/public`: Archivos estáticos (CSS, JS).

## Diseño

El sistema cuenta con un diseño premium utilizando tipografía moderna (Outfit), una paleta de colores profesional y una interfaz responsiva con barra lateral.
